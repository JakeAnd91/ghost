#Architecture
This is a document outline of the core ghost functionality.  


## Main Loop
Voice/Text Input
-> Speect-to-Text
-> Context Builder (memory + tools)
-> LLM 
-> Tool Calls
-> Response Formatter
-> Text-to-Speech  
-> Outuput

## Philosophy
I want this to be a personal assistant that not only learns from you but is smart and can grow alongside you. I want to capture that first feeling of waking up, and having something/someone by your side to record your adventures.

I also want to turn this into an open-ish source software where every person that downloads and initializes their 'ghosts' will get a random mix of personality traits, so that no two ghosts are identical.

They can have different:
 - Archetypes
 - Voices
 - gestures
 - tones
 - communication styles
 - initiatives
